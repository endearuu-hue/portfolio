# 문의 폼을 Gmail에 연결하기

포트폴리오 문의 폼은 Google Apps Script를 거쳐, 스크립트를 배포한 Google 계정의 Gmail로 메일을 보냅니다. 무료이고, 외부 폼 서비스를 거치지 않습니다. (무료 계정은 하루 100통까지 보낼 수 있습니다.)

## 1. 스크립트 만들기

1. https://script.google.com 에 메일을 받을 Gmail 계정으로 로그인합니다.
2. **새 프로젝트**를 만들고 이름을 `포트폴리오 문의`로 바꿉니다.
3. 기본 `Code.gs` 내용을 모두 지우고, 이 폴더의 `Code.gs` 내용을 붙여 넣은 뒤 저장합니다.

## 2. 웹 앱으로 배포하기

1. 오른쪽 위 **배포 > 새 배포**를 누릅니다.
2. 유형 선택에서 **웹 앱**을 고릅니다.
3. 이렇게 설정합니다.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포**를 누르고 권한을 허용합니다. "Google에서 확인하지 않은 앱" 경고가 나오면 **고급 > (프로젝트 이름)(으)로 이동**을 누르면 됩니다. 본인이 만든 스크립트라서 나오는 경고입니다.
5. 표시되는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.

## 3. 사이트에 주소 넣기

`index.html`에서 아래 줄을 찾아 복사한 주소를 넣습니다.

```js
const FORM_ENDPOINT = "";
```

```js
const FORM_ENDPOINT = "https://script.google.com/macros/s/여기에-복사한-ID/exec";
```

사이트에서 문의를 한 번 보내 보고, Gmail에 `[포트폴리오 문의]` 메일이 오면 연결이 끝난 것입니다. 메일에서 **답장**을 누르면 문의한 사람의 이메일로 바로 답장이 갑니다.

## 스크립트를 고친 뒤에는

`Code.gs`를 수정했다면 **배포 > 배포 관리 > 수정(연필) > 버전: 새 버전 > 배포**를 눌러야 반영됩니다. 이렇게 하면 URL은 그대로 유지됩니다.

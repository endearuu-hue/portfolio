현상하는 사람

영어로 developer는 현상액이면서 개발자예요.
필름은 약품 속에서 천천히 상이 올라오고, 코드는 한 줄씩 쌓이다 어느 순간 화면이 됩니다.
저는 두 가지를 다 현상합니다.

// 오늘 찍은 한 롤을 현상합니다
const roll = {
  film: "HP5 Plus 400",
  frames: 36,
  developer: "ID-11 stock",
  temp: 20, // °C
  time: "7:30",
};
 
await develop(roll); // 상이 올라오는 중
7:30

최근의 하루들

연출보다 그날 실제로 있었던 순간을 남깁니다.
손끝, 웃음, 걸음 같은 것들이요.

사진을 찍으며 배운 건,
그날은 다시 오지 않는다는 것.

코드를 짜며 배운 건,
다시 꺼내 볼 수 있게 만들 수는 있다는 것.

그래서 촬영이 끝나면 사진을 넘기는 데서 멈추지 않고, 두 사람이 오래 들여다볼 수 있는 자리까지 직접 만듭니다.

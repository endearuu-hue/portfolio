현상하는 사람

영어로 developer는 현상액이면서 개발자예요.
필름은 약품 속에서 천천히 상이 올라오고, 코드는 한 줄씩 쌓이다 어느 순간 화면이 됩니다.
저는 두 가지를 다 현상합니다.

// 오늘 찍은 한 롤을 현상합니다
const roll = {
  film: "HP5 Plus 400",
  frames: 36,
  developer: "ID-11 stock",
  temp: 20, // °C
  time: "7:30",
};
 
await develop(roll); // 상이 올라오는 중
7:30

최근의 하루들

연출보다 그날 실제로 있었던 순간을 남깁니다.
손끝, 웃음, 걸음 같은 것들이요.

두 개의 작업대

카메라 가방과 노트북 가방을 번갈아 메고 다닙니다.

사진을 찍으며 배운 건,
그날은 다시 오지 않는다는 것.

본식은 디지털로 빠짐없이, 스냅은 필름으로 천천히 남깁니다. 셔터를 누르기 전에 한 번 더 기다리는 게 제 방식이에요.

본식
디지털 두 대, 소리 없는 셔터
스냅
35mm와 중형 필름
보정
필름의 톤을 기준으로 맞춘 색

코드를 짜며 배운 건,
다시 꺼내 볼 수 있게 만들 수는 있다는 것.

사진 일을 하며 불편했던 것부터 직접 만들기 시작했어요. 지금은 의뢰받은 서비스도 같은 마음으로 만듭니다.
